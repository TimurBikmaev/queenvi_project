# QueenVi

Площадка для обмена контентом внутри фан-сообщества Twitch-стримерши. Повышает вовлечённость аудитории и ее взаимодействие со стримером.

Проект представляет собой **MVP бэкенда с API**. В дальнейшем планируется разработка frontend-части и передача проекта стримеру для реального использования.


## Возможности

### Пользователи
* аутентификация происходит через **Twitch OAuth**;
* авторизация через **django сессию (Cookie)**;
* в профиле используются **ник и аватар из Twitch**, но пользователь может **изменить аватар** на другой.

### Предложка

Пользователи могут:

* **предлагать видео из YouTube** для просмотра на стриме (вставить ссылку);
* указывать категорию (смешные, трукрайм, познавательные, трейлеры, разные);
* **голосовать** за видео из предложки.

Для ленты предусмотрена **сортировка по дате создания**, а также **фильтрация по категории**.

### Посты

Пользователи могут:

* публиковать фото, видео, аудио (максимальный размер поста — **до 500 МБ**);
* добавлять название и описание;
* публиковать в ленте **«для стрима»** и **«не для стрима»**;
* просматривать ленту постов;
* ставить **лайки** и **комментировать**;
* **жаловаться** на публикации.

Для ленты предусмотрена **сортировка по лайкам и комментариям**, а также **фильтрация по периоду создания публикаций, типу медиа, "для стрима"**.


### Модерация

На площадке может быть один стример и несколько модераторов. Назначать модераторов может только стример. Модераторы же могут рассмотривать жалобы и блокировать пользовательский контент.

В приложении также настроена админка. Администратор поддерживает работу проекта.

Для автоматизированного тестирования используется **Pytest**.

* моделям;
* бизнес-логике;
* API/представлениям;


## Развёртывание

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd QueenVi_project
```

### 2. Настройка переменных окружения

Создайте файл `.env`:

```env
DEBUG=False

SECRET_KEY=your-secret-key

POSTGRES_DB=queenvi
POSTGRES_USER=queenvi
POSTGRES_PASSWORD=your-password
POSTGRES_HOST=db
POSTGRES_PORT=5432

TWITCH_CLIENT_ID=your-client-id
TWITCH_CLIENT_SECRET=your-client-secret
TWITCH_REDIRECT_URI=https://your-domain.com/...
```

Секретные данные не должны храниться в репозитории.

### 3. Запуск Docker Compose

```bash
docker compose up -d --build
```

### 4. Выполнение миграций

```bash
docker compose exec web python manage.py migrate
```

### 5. Создание администратора

```bash
docker compose exec web python manage.py createsuperuser
```

### 6. Проверка работы

После запуска приложение будет доступно по адресу, настроенному в Nginx.

Для production рекомендуется использовать HTTPS.

## CI/CD

Для автоматической проверки проекта используется GitHub Actions.

При изменениях в репозитории выполняются автоматические тесты.

Production-деплой выполняется через Docker Compose, что позволяет обновлять приложение без необходимости вручную изменять конфигурацию контейнеров при каждом обновлении кода.

## Итоги проекта

QueenVi — это не просто учебный CRUD-проект, а MVP веб-приложения, рассчитанный на потенциальное реальное использование.

В рамках проекта реализуется полный backend-цикл:

* аутентификация через внешний OAuth-провайдер;
* работа с пользователями и правами доступа;
* хранение данных в PostgreSQL;
* загрузка и выдача медиафайлов;
* публикация пользовательского контента;
* лайки, просмотры и комментарии;
* система предложений YouTube-видео;
* модерация;
* автоматизированное тестирование;
* контейнеризация;
* production-развёртывание через Nginx и Gunicorn;
* CI/CD.

Основная цель MVP — получить работающий продукт, который можно использовать в реальном сообществе и впоследствии постепенно расширять новыми возможностями.
